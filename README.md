# SRooms

Приложение для настольных ролевых сессий через локальную сеть / Radmin VPN: лобби, доска 5×5 с комнатами (цвета видит только мастер), заметки, логи с бросками кубов, личные послания от мастера и листы персонажей по системе «Витрувий».

Стек: Kotlin, Compose Multiplatform (Desktop), Ktor WebSockets, kotlinx.serialization.

## Запуск (разработка)

```
gradlew run
```

Для локального теста на одной машине запустите вторую копию в другом терминале и подключитесь к `127.0.0.1:25575` (порт виден в шапке лобби; при конфликте портов берётся следующий свободный).

## Сборка

```
gradlew packageUberJarForCurrentOS   # jar под текущую ОС (build/compose/jars/)
gradlew packageUberJarAllOs          # один jar для Windows/macOS/Linux (нужна Java 17+)
gradlew packageMsi                   # Windows-инсталлятор со встроенной Java
gradlew packageDmg                   # macOS-пакет (только на macOS)
```

## Как играть

1. Хост: «Создать лобби» → сообщает друзьям свой IP из Radmin и порт из шапки лобби.
2. Игроки: имя → IP и порт хоста → «Войти».
3. В лобби выбираются цвета, хост назначает ГМа и стартует новую сессию или сейв (сейвы в `~/.srooms/saves/`).
4. Соло-старт = режим подготовки: мастер расставляет комнаты, цвета и заметки, сохраняет — и запускает сейв, когда соберутся игроки.

## Тесты

```
gradlew runSmokeTest   # headless-проверка сетевого протокола и игровой логики
```
